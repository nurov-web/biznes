## Фаза 1 — «Имрӯз» (2–3 ҳафта)

- **HOME / TODAY:** як экран — афзалияти рӯз, пул, мушкили асосӣ (EOS Rocks + myPNL actual vs plan).
- **Business health** хулоса: 72% + «чаро» + «имрӯз чӣ кор» (банди 16–17).
- **AI analysis stages** ҳангоми таҳлил (банди 23) — `EntryVeil` ё компоненти ҷудогона.
- Пайванди Pilot → `business` дар DB (аз `CHI-LOZIM-AST.md` P0-1).

# BusinessPilot AI — таҳқиқот ва техникӣ вазифа (ТЗ)

**Манбаъ:** [biznes-mu.vercel.app](https://biznes-mu.vercel.app/) (production), репозитории `bissnes`  
**Сана:** 2026-09-16  
**Контекст:** фидбэки муаллим (рейтинг 0) — «бизнесро пеш намебарад», «себ ва компютер — як план», лозим: план, архитектура, видео, китоб/скилл, CRM/MCP/Bitrix24, фаҳмо барои соҳибкор.

## Қисми 1. Таҳқиқот (исследование)

### 1.1. Мақсади маҳсулот (ҳозир дар лендинг)

Сайти зинда (`/tg`) мегӯяд:

- «Курс, маслиҳат ва нақшаи фурӯш — маҳсус барои шумо»
- Се қадам: анкета → вуруд/қайд → 4 пешниҳод + 6 дарс + нақшаи фурӯш
- AI витринаро мехонад; **на** Somon/OLX; **на** кафолати фоида

**Хулоса:** ваъдаи маркетингӣ **роҳнамои шахсӣ** аст. Муаллим инро бо **таҷрибаи воқеӣ** (себ = компютер) санҷидааст ва ҷудогӣ надидааст.

### 1.2. Чӣ дар код ва production воқеан кор мекунад

| Қисм | Ҳолат | Далил (код / UI) |
|------|--------|------------------|
| Анкета «бизнес дорам» | Кор мекунад | `has-business` → `POST /api/analyze-business` |
| 4 пешниҳоди AI | Кор мекунад, бо fallback | `services/ai/pilot.ts` — `analyzeBusinessSuggestions` + `fallbackFor()` |
| Нақшаи фурӯш (матн) | Кор мекунад | `POST /api/generate-plan` → `generateSalesPlan` |
| Курс 6 модул | Кор мекунад, **умумӣ** | `constants/pilot-course.ts`, `messages/pilotCourse` — мавзӯъҳои умумӣ; `m1a`…`m6a` танҳо `{product}`, `{region}`, `{price}`, `{volume}` иваз мекунанд |
| Операционка (CRM, POS, анбор, молия) | Кор мекунад | Sidebar: dashboard, pos, inventory, finance, crm + «More» (learn, plan, simulator, agents, …) |
| Роҳнамои «4 қадами рӯз» | **Намоиш дода намешавад** | `PurposeMap`, `RunBusinessGuide`, `SetupChecklist`, `RescueBoard` — **ҳеҷ импорт дар саҳифаҳо нест** |
| Видео | **Нест** | Танҳо стил CSS барои `<video>` |
| Архитектура (схемаи бизнес) | **Нест** | Нақша = матни AI; схемаи канал/анбор/пул визуалӣ нест |
| Bitrix24 | **Нест** (queued) | `integrations/page.tsx` — Shopify/Woo/Instagram queued |
| MCP | **Намуди тарҳӣ** | `services/ai/tools.ts` — tool-calling барои Claude; пайвасти берунаи MCP server нест |
| Нишаи «себ» vs «компютер» | **Қисман** | `lib/niche.ts` — табдили калимаҳо; **плейбуки алоҳида** (фасод/гарантия) нест |
| Забони лендинг vs продукт | **Номувофиқат** | Лендинг: «бе CRM-и сохта»; дар барнома CRM пурра ҳаст |

### 1.3. Чаро муаллим «рейтинг 0» дода метавонад (критерияи одилона)

1. **Якхелагии пешниҳодҳо:** ҳангоми хатои AI ё калиди нодуруст, `fallbackFor` барои ҳама бизнес шаблонҳои якхела медиҳад («3 харидор», «дар баста») — фақат номи маҳсулот иваз мешавад.
2. **Курс якхела:** модулҳои 1–6 барои соҳиби себ ва соҳиби компютер **ҳамон матн**; танҳо ҷумлаи `apply` персонализацияи суст дорад.
3. **«Пеш бурдан» номаълум:** пас аз интихоби роҳ, пайванди қатъӣ ба POS/CRM («имрӯз ин корро кун, баъд ин тугмаро пахш кун») дар dashboard асосӣ суст; роҳнамои омода (`PurposeMap`, `RunBusinessGuide`) истифода намешавад.
4. **Архитектура ва видео:** талаби муаллим қонеъ намешавад.
5. **Печониданӣ:** 10+ модул дар «More» — барои «одами садда» душвор.
6. **Идея зур:** системаи `business-system.ts`, pilot flow, операционка — **асоси хуб**; муаллим имкониятро дид, аммо **таҷрибаи соҳибкор**-ро ноком донист.

### 1.4. Таҳлили рақибӣ / аналог (концептуалӣ)

| Решение | Қувват | Фарқ аз BusinessPilot |
|---------|--------|------------------------|
| Bitrix24 | CRM, воронка, задачҳо, интегратсия | Забон, мураккабӣ, нарх; на барои дӯкони 1 нафар |
| ChatGPT | матни умумӣ | бе POS/анбор, бе қоидаҳои TJS |
| Shopify | витрина + фурӯш | на маслиҳати TJ, на курс тоҷикӣ |

**Нишаи BusinessPilot:** соҳибкори хурди Тоҷикистон — **қадами рӯз + забон + ҳисоби сомонӣ + қайд дар система**.

### 1.5. Матрица: CRM / Bitrix24 / MCP — кадом бизнес?

| Ниша | CRM (дохилӣ) | Bitrix24 | MCP-style tools (AI + дода) |
|------|----------------|----------|-----------------------------|
| Мева/себ, нон, хӯрок | **Асосӣ** — мизоҷ, фурӯш, ҳафта | Одатан **лозим нест** (<5 корманд) | AI: фасод, мавсим, баста, нарх/кг |
| Савдо (смес, либос) | **Асосӣ** | Ихтиёрӣ | AI: маржа, dead stock |
| Телефон/компютер/IT | **Асосӣ** + пайгирии гарантия | **Муфид** — лид, заказ | AI: модел, маржа, хизмат |
| Хидмат (таъмир, салон) | CRM + вазифаҳо | **Хуб** — календар | AI: нархи хидмат, қабул |
| Онлайн (Instagram) | Webhook + CSV | Bitrix агар даста бошад | AI: контент + нақшаи ҳафта |
| Опт/B2B | Анбор + молия | **Тавсия** | AI: cash conversion |

**Қоидаи маҳсулот:** дар UI **на** рӯйхати 10 интегратсия — **1 блок «Барои бизнеси шумо»** пас аз анкета.

## Қисми 2. Техникӣ вазифа (ТЗ)

### 2.1. Ном ва мақсад

**Ном:** BusinessPilot AI — платформаи роҳнамоии соҳибкори хурд (TJ).  
**Мақсади нав (пас аз таҳқиқот):** на танҳо «AI + CRM», балки **роҳи қатъӣ** аз анкета то қайди фурӯши ҳаррӯза, бо **фарқи ниша**, **схема** ва **видеои кӯтоҳ**.

### 2.2. Истифодабарандагон

| Персона | Эҳтиёҷ |
|---------|--------|
| Соҳибкори нав | «Чӣ кор кунам имрӯз?» — бе терминология |
| Соҳибкори фаъол (себ, телефон, …) | нақшаи ҳафта, рақам, пешниҳоди мушаххас |
| Муаллим / комиссия | 2 демо, фарқи ниша, архитектура, идеяи илмӣ |
| Админ | API key, webhook (ҳозир ҳаст) |

### 2.3. Усулҳои кор (scope)

**Дар ҳудуди ТЗ:**

- Плейбуки ниша ва промпти махсус
- UI «Имрӯз» + архитектура
- Видео embed + матни дарс
- Матрицаи интегратсия (маълумотӣ + roadmap Bitrix)
- Содакунии навигатсия
- Истифодаи компонентҳои dashboard мавҷуда

**Берун аз ҳудуд (фазаи баъдӣ):**

- Скрейпинг Somon/OLX
- Bitrix24 пурра (OAuth, синхрони воронка)
- MCP server берунӣ (танҳо документатсия + истифодаи `BUSINESS_TOOLS` дохилӣ)
- Иловаи мобилӣ алоҳида

### 2.4. Талаботи функсионалӣ

#### FR-1. Плейбуки ниша (P0)

- **Вуруд:** `category`, `subcategory`, `product`, `niche` аз `lib/niche.ts`.
- **Хуруҷ:** набори `rules`, `forbiddenAdvice`, `stepTemplates`, `planSections` барои ҳар `NicheId` ё хатти `produce` vs `tech` vs `service`.
- **Интегратсия:** `analyzeBusinessSuggestions` ва `generateSalesPlan` — қоидаҳои плейбук дар system prompt; fallback **аз плейбук**, на танҳо `fallbackFor` умумӣ.
- **Қабул:** барои «себ» ва «смартфон» ҳадди ақал 3 аз 4 сарлавҳаи пешниҳод **фарқи маънодор** доранд (фасод/кг vs гарантия/маржа).

#### FR-2. Экран «Имрӯз» (P0)

- **Ҷойгиршавӣ:** `/dashboard` таби асосӣ ё `/today` (redirect аз dashboard).
- **Мундариҷа:**
  - қадами интихобшуда аз 4 пешниҳод (чеклист 3 қадам);
  - `RunBusinessGuide` (анбор → CRM → POS → молия);
  - тугмаи асосӣ ба қадами навбатӣ.
- **Қабул:** бе менюи «More» корбар метавонад аввалин фурӯшро сабт кунад (бо `SetupChecklist`).

#### FR-3. Архитектураи бизнес (P0)

- **Компонент:** `BusinessArchitectureMap` (нав) ё расми `PurposeMap` + блок каналҳо (`channels` аз профил).
- **Намоиш:** пас аз анкета (preview) ва дар dashboard.
- **Қабул:** SVG/Mermaid статикӣ + матни кӯтоҳ; чопшаванда.

#### FR-4. Видео (P1)

- **Манбаъ:** URL дар `messages` ё `constants/video-lessons.ts` (YouTube/Loom).
- **Минимум:** 4 клип (анбор, CRM, POS, «чӣ тавр нақшаро иҷро кунем»).
- **UI:** `<iframe>` ё `<video>` дар модул 1 ва дар «Имрӯз».

#### FR-5. Курс бо трак (P1)

- `pilotCourse` → `pilotCourseFood` / `pilotCourseTech` (ё `contentKey` вобаста ба niche).
- Модулҳои 3–4 махсус (маркетинг мева vs маркетинг техника).

#### FR-6. «Асбобҳо барои шумо» (P1)

- Саҳифа `/integrations/advice` ё блок дар `/integrations`.
- Логика: `recommendIntegrations(profile)` → `{ crm: 'built-in', bitrix: boolean, mcp: 'ai-tools' }` + матни фаҳмо.

#### FR-7. AI бо асбобҳо (P2)

- Дар чат/агентҳо: ҳангоми саволи «вазъияти ман» — `get_business_snapshot` (аллакай дар `tools.ts`).
- UI: «Маълумот аз анбори шумо» (badge).

#### FR-8. Лендинг ва матн (P1)

- Тавозун кардани «бе CRM» бо «CRM сода барои қайд» — як паём.

### 2.5. Талаботи ғайрифунксионалӣ

- Забонҳо: tg, ru, en (`messages/*.json`) — бе hardcode.
- TypeScript strict, бе `any`.
- AI танҳо `src/services/ai`.
- Мобил: тугма ≥48px, таби «Имрӯз» аввал.
- Хатогӣ: try/catch, лог; fallback плейбук ҳангоми хатои Claude.

### 2.6. Архитектураи техникӣ (тағйирот)

```
src/constants/playbooks/
  index.ts          — индекс niche → playbook
  produce.json      — себ, мева, хӯрок
  tech.json         — телефон, компютер
  service.json      — хидмат

src/components/journey/
  TodayBoard.tsx
  BusinessArchitectureMap.tsx
  IntegrationAdvice.tsx

src/app/[locale]/(app)/today/page.tsx   — (ихтиёрӣ)

services/ai/pilot.ts                    — inject playbook
```

**Дода:** ҳозир `data/app.json` / PostgreSQL — бе тағйири схема барои FR-1–6; `pilotProfiles` аллакай дорад.

| Фаза | Мӯҳлат (тахминӣ) | Натиҷа |

| **F0** | 1–2 рӯз | Ин ҳуҷҷат + 2 сценарии демо (скриншот) |

### 2.8. Критерияи қабули умумӣ (UAT)

1. Ду корбари тестӣ (себ / компютер) — пешниҳодҳо ва нақша **васеъ фарқ**.
2. Корбари нави бе таҷриба — аз вуруд то 1 фурӯш ≤ 15 дақиқа (бо дастур).
3. Dashboard нишон медиҳад: роҳи интихобшуда + 4 қадами рӯз + схема.
4. Learn: ҳадди ақал 1 видео кор мекунад.
5. Integrations: матни «Bitrix лозим нест / лозим аст» дуруст барои ниша.

### 2.9. Рискҳо

| Риск | Тасҳвиш |
|------|---------|
| AI бе калид | Плейбук + fallback аз niche, на шаблон умумӣ |
| Муаллим «зиёд модул» мебинад | F2: меню 5 пункт |
| Видео нест | Embed URL — сабти экран 1 соат |

### 2.10. Action items барои иҷро (баъд аз тасдиқи ТЗ)

3. Пур кардани `playbooks/produce.json` ва `playbooks/tech.json` (муаллим/донишҷу).
4. Иҷрои F1 дар код (Agent).

# Чӣ ҳозир лозим аст (таҳқиқоти код + production)

**Сана:** 2026-09-16  
**Принсип:** сайтро аз сар **накун** — танҳо фосилаҳое, ки муаллим «бизнесро пеш намебарад» мегӯяд ва соҳибкор «лозим нест» мешавад.

---

## 1. Хулосаи як ҷумла

Сайт **ду ҷаҳон** дорад, ки пайваст нашудаанд:

1. **Pilot** — анкета, 4 роҳ, курс, нақшаи матн (`/dashboard` → танҳо `/api/pilot/state`).
2. **Операционка** — анбор, CRM, POS, молия (`/api/dashboard` дода медиҳад, **ҳеҷ UI истифода намебарад**).

Соҳибкор пас аз анкета ба dashboard меравад, вале **бизнес дар DB набошад**, касса/анбор **NO_BUSINESS** мегиранд. Роҳнамои «4 қадами рӯз» (`PurposeMap`, `RunBusinessGuide`) **навишта шуда, вале дар саҳифа намоиш дода намешавад**.

## 3. Лозим аст — ҳадди ақал (P0)

### P0-1. Пайванди Pilot → бизнес (критикӣ)

**Мушкил:** `analyze-business` танҳо `pilotProfile` месозад; `business` эҷод намешавад.  
**Натиҷа:** соҳибкор «пешниҳод» мегирад, вале **касса/анбор кор намекунад** — сайт «пеш намебарад».

**Лозим:**

- Пас аз анкета (ё аввалин вуруд ба app): **business хурд** аз профил (`name` = маҳсулот ё «Дӯкони {product}», `city` = region).
- **Ихтиёрӣ:** 1 мол дар анбор аз `product` + `price` (қадами «имрӯз» осон мешавад).

**Қабул:** корбари pilot-only метавонад `/inventory` ва `/pos` бе хатои 409 кушояд.

---

### P0-2. Dashboard = «Имрӯз» + операционка

**Мушкил:** `dashboard/page.tsx` танҳо pilot; `/api/dashboard` **ҳеҷ куҷо fetch намешавад**.

**Лозим (компонентҳои мавҷуда):**

- `RunBusinessGuide` — дода аз `guide` дар `/api/dashboard`.
- `PurposeMap` — `salesCount` = `guide.sales`.
- `SetupChecklist` — танҳо 4 қадами асосӣ (анбор, CRM, POS, молия) — **на** 7 қадам бо competitors/learn, агар душвор шавад.

**Қабул:** бе менюи «More» корбар «Ҳозир» → тугмаи ба анбор/касса мебинад.

---

### P0-3. Себ ≠ компютер (на қайд кардани сайт)

**Мушкил:** `fallbackFor()` шаблони умумӣ; AI бе калид ҳамон шаблон.

**Лозим:**

- Файли қоидаҳо: `produce` | `tech` | `service` | `general` (аз `resolveNiche(product, category)`).
- Дар `analyzeBusinessSuggestions` + `generateSalesPlan`: 5–10 сатр қоидаи ниша дар prompt.
- Fallback **аз ниша**, на танҳо `fallbackFor` умумӣ.

**Қабул:** «себ» ва «смартфон» — ҳадди ақал 2 сарлавҳаи пешниҳод ва 1 қадами нақша **фарқи маънодор**.
